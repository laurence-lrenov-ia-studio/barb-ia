# Barbara se met à l'IA — Guide de déploiement

## 📦 Les 4 fichiers à déposer

```
📂 barbara-ia/
   ├── index.html              ← page principale (ce que Barbara voit en premier)
   ├── barbia-mockup.html      ← aperçu mobile : appli complète Barb.IA (3 écrans)
   ├── fitnow-mockup.html      ← aperçu mobile : FitNow! CRM (3 écrans)
   └── shakenow-mockup.html    ← aperçu mobile : ShakeNow! Bar (3 écrans)
```

## 🚀 Comment déployer

### Option 1 — GitHub Pages (recommandé · gratuit)

1. Crée un repo GitHub : `barbara-ia` (ou ce que tu veux)
2. Dépose les 4 fichiers à la racine
3. Settings → Pages → Source : `main` branch / `/root`
4. Tu obtiens l'URL : `https://laurence-lrenov-ia-studio.github.io/barbara-ia/`
5. Tu envoies cette URL à Barbara

### Option 2 — Hostinger (ton site principal)

1. Crée un sous-dossier `/barbara/` dans ton FTP
2. Dépose les 4 fichiers dedans
3. URL finale : `https://lrenov-ia.studio/barbara/`

### Option 3 — Netlify drop

1. Va sur https://app.netlify.com/drop
2. Glisse-dépose le dossier complet
3. Tu obtiens une URL instantanée

## 🔗 Navigation entre les pages

- **index.html** est la porte d'entrée — c'est cette URL que tu donnes à Barbara
- Dans l'onglet **FitNow!** → clic sur "Voir l'aperçu mobile" → ouvre `fitnow-mockup.html`
- Dans l'onglet **ShakeNow!** → clic sur "Voir l'aperçu mobile" → ouvre `shakenow-mockup.html`
- Sur les mockups → bouton "Retour" en haut à gauche → ramène à `index.html`
